# Projet — Personnalisation de ma TV Samsung

## But
Personnaliser **ma propre** télévision Samsung (UE55NU7175, 2018, Tizen 4.0) pour
rendre son usage plus agréable :

1. **Remap du bouton Home** : on cherche un moyen de réassocier le bouton Home de
   la télécommande pour lancer autre chose que le Smart Hub Samsung.
2. **Un lanceur d'accueil maison** : une petite application web Tizen (HTML/CSS/JS)
   qui affiche mes applications sous forme de grille, navigable à la télécommande.
   Installée via le mode développeur officiel de Samsung + Tizen Studio.
3. **Nettoyage des réglages** : désactiver les options d'accueil superflues pour
   réduire les lenteurs au quotidien.

C'est un projet personnel de confort, sur un appareil qui m'appartient, avec les
outils de développement fournis par Samsung.

## Cadre
- Outils : Tizen Studio 6.1 (CLI) installé dans `C:\Users\theor\tizen-studio`,
  `sdb` dans `tools\sdb.exe`.
- La TV est en mode développeur, connectée à `sdb` (IP 192.168.1.23:26101).
